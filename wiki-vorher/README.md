# Wiki-Seiten, so wie sie wirklich sind

Drei Seiten aus dem Wiki der Fahrradwerkstatt. Alle drei erklären irgendwo, was ein „Auftrag" ist. Alle drei sagen etwas anderes. Keine ist als veraltet markiert.

Das ist kein Ausnahmefall. So sieht fast jedes Wiki nach drei Jahren aus.
